Промт — инструкция для модели: что сохранить, какой фон и свет. Правка вступает в силу для следующих генераций, уже сделанные снимки не меняются. У каждого снимка на экране проверки видно, какой версией промта он сделан. Если после правки стало хуже — верните прошлую версию из истории. Промт лучше писать по-английски: модель держит такие ограничения надёжнее; замечания к «Переделать» можно писать по-русски.
