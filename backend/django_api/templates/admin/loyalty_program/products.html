Правила, которые не меняются

  • Уценённые товары (старая цена больше цены) — не оплачиваются бонусами. Правило ТЗ, зашито в код; бонусы за их покупку начисляются.
  • Доставка — не оплачивается бонусами и бонусов не даёт. Правило ТЗ, зашито в код.
  • Оплатить бонусами можно не больше {{ hard_ceiling }}% суммы допущенных товаров на любом уровне.
  • Бонусы начисляются только на часть заказа, оплаченную деньгами.
