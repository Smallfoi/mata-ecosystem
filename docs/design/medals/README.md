# Штамп МАТА — система наград Квартала

**Утверждено владельцем 2026-09-01** (9 итераций). Живой дизайн-документ:
[`shtamp-mata.html`](shtamp-mata.html) — открыть в браузере, всё рендерится
и анимируется на месте (чистый SVG + CSS/SMIL, без зависимостей).
Артефакт для просмотра/шаринга: https://claude.ai/code/artifact/812897a7-bbb5-4c80-9714-965c2eb63497

## Система в одном абзаце

44 награды, один шестигранный штамп — форма квартала карты (вершиной вверх, R=50).
**Кант держит категорию** (полировка · насечка · рифление · витой трос · бисер),
**металл держит ранг** (сталь → бронза → серебро → золото → иридий),
**эмблема держит награду**. Эмаль (лайм/голубой/лёд) — только иридий и отдельные
лимитированные. Категории: Ритм 11 · Территория 9 · Дистанция 11 · Сезон и лига 7 ·
Лимитированные 6.

## Правила, выстраданные итерациями (нарушение = откат владельцем)

1. **Никаких наложений** — ни в текстах, ни в деталях. Все зазоры считать геометрией
   (шестиугольник сужается к вершинам быстрее, чем кажется). Надписи — только по
   круговым дугам (на шестиугольной дорожке буквы сталкиваются в углах).
2. **Никакой «паутины»** — фон поля только азурирование (концентрические круги без
   лучей), кольца не заходят в пояс надписей.
3. **Эмблема — иллюстрация, не пиктограмма.** Многослойная художественная чеканка
   почти на всё поле; счётчики (серии/недели/кратности) — строгая гравюра.
4. **Цифры и год — на графитовой плашке** с металлическим кантом; в эмалевом канте
   под плашку вырезается окно (mask), плашка не ложится на эмаль.
5. **У каждой медали своя анимация самой эмблемы** — общий крутящийся фон запрещён
   как «ленивый». Щит принимает стрелу, перехват делает один оборот и замирает,
   район смагничивается, разметка бежит, солнце восходит, крылья взмахивают,
   окна загораются, снег идёт, лучи ордена вращаются. При появлении — «чеканка»:
   эмблема вбивается, плашка выезжает снизу, дуга проявляется.
   Пульсаций/ударных волн нет (D-46 про знак Квартала соблюдён по духу).
6. **Медали именные**: реверс с личной гравировкой (пик зон, время, дата, город),
   тап — чистый 3D-переворот без подскока. Город лимитированных — из GPS пробежки.
7. Палитра и шрифты — только из системы Квартала: `app_colors.dart`
   (лайм #DFF45F, голубой #57BCD8, графит #20252B), Unbounded + Manrope.

## v2 — «торжество» (утверждено владельцем 02.09.2026)

По списку замечаний владельца эмблемы перестали быть «топорными»:
- простые глифы Ритма стали иллюстрациями со своими анимациями (кольцо цели
  замыкается и вбивает галочку; неделя — лесенка дней с чеканной «7»; календарь
  месяца заполняется волной; годовое кольцо с обходящим бликом; шевроны нормы;
  бегунок-комета пробегает маршрут серии);
- оборона: ТРИ детализированные стрелы (наконечник/древко/оперение) с разных
  сторон впиваются в щит, ОСТАЮТСЯ торчать и тают; щит вздрагивает на каждый удар;
- рассвет по-настоящему всходит из-за горизонта (клип по линии) и садится;
  полночь получила метеор и спящие крыши;
- кубок празднует: конфетти, серпантин, глинты; дивизионы — самоцвет крупнее
  + звезда ранга; сэргэ резной, солнце живое, вокруг — осуохай (5 фигурок);
- лента Победы — волна из трёх штрихов по одной осевой (3 чёрных + 2 оранжевых),
  обвивает нижний луч звезды, колышется, ласточкины хвосты;
- фейерверки над Днём города, гирлянда ёлки мигает;
- цифры на плашках отцентрованы оптически (базовая линия = центр + полкапители);
- **новое правило**: у медалей без плашки имя награды гравируется по нижней
  дуге — «за что выдана» читается с аверса.

## Как обновлять

Файл самодостаточен: медали генерируются JS-функцией `renderMedal()` из списка
`SERIES` (там же требования выдачи), эмблемы — объект `EMB`, металлы — `METALS`.
Добавить медаль = добавить элемент в `SERIES`; новый год чекана = поле `year`.
После правок — перепубликовать артефакт по тому же URL и перечеканить ассеты
приложения конвейером (см. ниже).

## Конвейер в приложение (работает с 02.09.2026)

Ассеты Лиги выгружаются из ЭТОГО файла попиксельно: страница открывается в
Chrome (chrome-devtools MCP), каждый `renderMedal()` собирается в standalone-SVG
(инлайн-шрифты data:-URI, вырезанный sheen, xmlns, дедуп атрибутов через
HTML-парсер) → canvas 768×768 → WebP q0.92 → `mata_liga/assets/medals/<id>.webp`
(44 аверса + 5 баз реверса по металлам). Скрипт конвейера — в WORKLOG 2026-09-02.
Анимации в приложении переигрываются средствами Flutter (чеканка, блик, 3D-оборот).

## Послойный конвейер живых эмблем (с 05.09.2026, партиями)

Помедальные анимации эмблем переносятся в приложение так: та же страница в
Chrome, для медали размечаются ЖИВЫЕ узлы (SMIL/CSS эталона), статика режется
на сегменты ПО ДОКУМЕНТНОМУ ПОРЯДКУ вокруг них (z-порядок: лучи ордена под
звездой, плашка поверх щита), каждый сегмент и каждый живой узел выгружается
отдельным прозрачным WebP на полном холсте 768 (позиции совпадают сами) →
`mata_kvartal/assets/medals/anim/<id>__<part>.webp`. Таймлайны SMIL/CSS
переводятся руками в ключи `emblem_motion.dart` (координаты ×esc/ey из
`renderMedal`). Грабли: скрытые узлы ПРЯТАТЬ visibility, не удалять — у
отсоединённых узлов ломается compareDocumentPosition и сегменты режутся мусором.
Грабли слоёв: (а) у слоя внутри SVG-клипа снимать clip-path у предков —
Chrome прячет контент clipPath вместе со скрытым корнем и слой вырезается
в ноль (клип переигрывается Flutter-Rect'ом); (б) сбрасывать не только
opacity="0", но и fill-opacity="0". Страж: emblem_assets_audit_test
(пустой слой = красный CI). Гравировка реверса ужимается engravingFitToWidth.
Проверка: `EMBLEM_FRAMES_DIR=… flutter test test/tool_render_emblem_frames_test.dart`
— стоп-кадры цикла; кадр t=0 обязан совпадать с статичным аверсом.
Пилот: s_champion (лучи), d_dawn (восход за горизонт), t_defense_7 (стрелы+щит),
d_first_run (бегун/полосы/искры). Остальные 40 — партиями этим же конвейером.

## План на 2027

- Год на плашке лимитированных — **новый чекан каждый год** (медаль-2027 ≠ 2026);
  серию 2027 строить на этом же штампе, меняя эмблемы/приметы событий.

## Технические грабли SVG (подробнее в docs/PITFALLS.md)

textPath по многоугольнику с углами; CSS transform-box/transform-origin на вложенных
SVG-группах (лучи уезжали — лечится SMIL `animateTransform`); дуга `A` с радиусом
меньше половины хорды молча раздувается (луна становилась кругом — серп собран маской);
CSS-анимация transform затирает атрибут `transform` (нужны вложенные обёртки).
