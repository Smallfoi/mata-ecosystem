## 1. Хронология событий

### Предыстория (до 13.06.2026 — в журналах почти нет)

**1. 23.05.2026 — Родился PRD «Квартала»: «Городское беговое соревновательное приложение для Якутска»** · 🔀
- Что: документ v1.1 со стеком Go + PostgreSQL + PostGIS и картой Якутска, порезанной на **гексагоны H3**. Слоган: «Сделай Якутск своим — бегай, захватывай районы, становись легендой города». Якутск-специфика: −50°C, зимний ультра-вызов, якутские орнаменты в паттернах.
- Зачем зрителю: точка отсчёта — можно показать, как далеко ушёл продукт от первого замысла (Go и гексы позже отвергнуты).
- Кадр: скрин PRD с гексагонами рядом с сегодняшней картой с реальными полигонами: «Так мы думали в мае. Так это выглядит сейчас».

**2. май–июнь 2026 — Магазин на моках + «письмо от Nike»** · 🔀
- Что: Sport Store — MVP на фейковых данных; для него написано «рекомендательное письмо» по опыту Nike/Adidas/Gymshark: «Топовые бренды делают не магазин, а экосистему: пришёл, вернулся, тренировался, получил баллы, купил снова». Отсюда и родилась идея экосистемы.
- Зачем зрителю: объясняет, почему это не «ещё один магазин» и не «ещё одно беговое приложение».
- Кадр: цитата на экране + схема «Бег → баллы → магазин → бег».

**3. до 13.06 — «Walking skeleton»: FastAPI + SQLite, единый аккаунт и баллы** · 🏆
- Что: первый вертикальный срез — один номер телефона → один аккаунт в двух приложениях; на телефоне доказано: заработал баллы в Квартале, увидел в Store.
- Зачем зрителю: с самого первого дня ядро было про «единый пользователь», остальное наросло вокруг.
- Кадр: два телефона / два экрана рядом — один аккаунт, одна цифра баллов.

## 2. Хребет истории — арки

Формат: название · даты · драматургия (проблема → поворот → результат) · события из раздела 1.

**А1. «Один аккаунт на всё»** · до 13.06 → 18.06
Проблема: три продукта (бег, магазин, сайт) — три разных мира. Поворот: «письмо от Nike»: не магазин, а экосистема; первый срез — один номер телефона = один аккаунт и один счёт баллов. **А2. «Переезд на Django за один день»** · 13.06 → 16.06
Проблема: FastAPI + SQLite не тянут территории — нужен PostGIS. Поворот: Docker не стартует без WSL2 — владелец ставит сам; ядро переносится с байт-в-байт совместимыми токенами. Результат: 15.06 всё на Django, приложения даже не перелогинились; 16.06 FastAPI удалён. (11, 12, 14)

**А3. «Квартал вместо гексагонов: территория — это твой маршрут»** · 23.05 (PRD) → 05.09
Проблема: в PRD город порезан на гексагоны. Поворот: D-09 «территория = полигон реального маршрута, НЕ гексы»; дальше — 7 дней живого слоя + вечный след (D-14), защита свежего захвата, античит.
