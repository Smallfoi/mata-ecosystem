## Правила кампании (коротко)

1. **Сериал ведут двое:** Михаил (улица, телефон, решения) и Claude (терминал, ночные смены,
   дневник). Счётчик «День N» — от первого коммита 13.06.2026 (06.09.2026 = день 86).
2. **Две линии:** «Архив» (событие из банка, хронологически) и «Сегодня» (тестеры, забеги,
   баги). Суббота — «Улица» (живой забег), воскресенье — «Эпизод недели» 50–60 с.
3. **Формула:** хук ≤3 с (цифра / провал / парадокс) → карточка «Квартал. День N» + «зачем» (1 с)
   → показ «было → стало» → вопрос зрителю. Субтитры вшиты всегда. Один и тот же первый кадр.
4. **Слово-CTA «КВАРТАЛ»** — только с ботом-автоответчиком в Telegram; ссылка на тест —
   mata-club.ru/app. В Instagram* — только вопрос, без «скачайте» (см. п. 6).
5. **Площадки:** VK Клипы (основной), Telegram (штаб, бот, бэкстейдж), YouTube Shorts,
   Instagram* (хроника без призывов), зеркала Max/RuTube. TikTok — нет.
6. **Закон (72-ФЗ с 01.09.2025):** в Instagram*/Facebook* и на заблокированных ресурсах
   запрещена любая реклама (нативная, бартер, промокоды, «скачайте»); нельзя платить Meta;
   нельзя звать в VPN; упоминание — с пометкой «*принадлежит Meta, признанной экстремистской
   и запрещённой в РФ»; реклама у блогеров на любой площадке — только с ERID.
7. **Ничего не фейкаем:** цифры — из журнала и git; провалы показываем как есть.
8. **Личные данные в эфир и в этот репозиторий не попадают** (репо публичный): телефоны,
   адреса, реквизиты, лица тестеров без согласия.

## Протокол работы (команды владельца)

- «Что снимаем сегодня» → карточка съёмки: хук, кадры по секундам, текст голоса, титры,
  финал, пост в Telegram (образцы — в `plan-365.html`, раздел 7).
- «План на неделю» → 7 карточек с учётом событий проекта за неделю.
- «Разбор недели: …» + цифры → анализ и корректировка календаря.
- «Новый факт: …» → событие в `CONTENT_BANK.md` с датой.
- «Снял день N» → отметка в `CALENDAR.md`, следующие дни сдвигаются.

Без команды Claude раз в неделю: читает WORKLOG/DECISIONS/коммиты всех сессий → пополняет банк;
держит календарь на 4 недели вперёд; готовит скриншоты и данные для титров; следит за датами
Якутска (забеги, гранты) и юридическими рамками формулировок.

## Метрики (просить у владельца еженедельно)

По ролику: просмотры, удержание на 3-й секунде, досмотры, сохранения, комментарии, отправки.
По каналам: подписчики. По продукту: установки, недельно активные, комментарии «КВАРТАЛ».
Пороги: удержание 3 с > 70%; «удержание эпизода 2» > 30%; рост установок в дни «Улицы».
Ориентиры 90 дней: 300 установок, 100 недельно активных, 10 амбассадоров, 3 очных ивента,
1 000 подписчиков суммарно VK+TG.
