# МАТА Старты — платформа для организаторов забегов (D-135)

Решение владельца 23.11.2026: направление «Старты» размораживается и становится платформой,
на которой организатор проводит старт от положения до протокола, а бегун находит забег,
записывается и видит результат. Опора — автоматизация и ИИ. Доход — комиссия с оплаченной
регистрации. Спонсоры — позже, когда соберётся аудитория. КП для организаторов —
документ «МАТА Старты — предложение организаторам забегов» (Claude Docs, у владельца).

## Что уже есть (на 23.11.2026)

| Часть | Состояние |

## Этапы (порядок = порядок КП)

**1. Публикация** — начинаем сразу:
- кабинет организатора (вход по телефону, как у всех; роль «организатор» на свои старты);
- ИИ собирает карточку старта из загруженного положения (PDF/Word): дата, место, дистанции,
  лимиты, цены, группы — организатор проверяет и публикует (модерация МАТА на первом шаге);
- «Планирую» уходит на сервер, организатор видит счётчик; поле «открытие регистрации» и
  напоминание о нём;
- приглашения бегунам региона (уведомления в приложении), по дистанции под их уровень;
- убрать демо-записи, наполнить афишу Якутии; включить `showRaces`.

**2. Регистрация и оплата:**
- регистрация на дистанцию из профиля, оплата СБП через ЮKassa, чек; лимиты, лист ожидания,
  ступени цены, промокоды, командные заявки, передача слота, возврат по правилам старта;
- ИИ-помощник отвечает участникам по положению (движок — как ИИ-продавец Pareta), сложное —
  организатору; рассылки по событиям старта.

**3. Старт и итоги:**
- загрузка протокола хронометража → финиши в профилях, личные рекорды, баллы за финиш;
- онлайн- и гибридный формат через трекер Квартала и часы (D-108);
- аналитика организатора: регистрации по дням, «планируют», повторные участники, прогноз.

**4. Спонсоры** — когда будет аудитория: витрина партнёров старта, предложения участникам.

## Открытые вопросы владельцу (до этапа 2)

1. **Схема денег.** Приём взносов за чужую услугу = агентская схема (МАТА — агент организатора)
   или расщепление платежа в ЮKassa (выплаты организатору). Нужны юрист и бухгалтер:
   договор-оферта для организатора, чеки (54-ФЗ: признак агента, ИНН поставщика), налог с комиссии.
2. **Размер комиссии** — в КП «согласуем на встрече».
3. **Медсправки** не храним: это данные о здоровье (152-ФЗ, особая категория). Проверку справки
   оставляем организатору на выдаче номеров.
