## Идеи по Runner App

### 💡 Ресурс кроссовок (трекер износа)

**Суть:** Показывать пользователю сколько км осталось у его кроссовок до замены.

**Как работает:**
- Пользователь купил кроссовки в Sport Store → они автоматически регистрируются в Runner App
- Runner App отслеживает каждую пробежку и накапливает километраж именно в этих кроссовках
- При регистрации или в настройках профиля собираем **антропометрические данные**: вес, рост, стиль бега (пронация/супинация)
- По **формуле динамики износа** (км × коэффициент веса × коэффициент стиля бега) считаем реальный остаток ресурса
- Приложение показывает: "Осталось ~230 км из 600 км" — в виде прогресс-бара или счётчика
- Носит **рекомендательный характер** — не жёсткое ограничение, а подсказка
- Когда ресурс на исходе — пуш-уведомление + рекомендация новой модели из Sport Store

**Где интегрировать:** Runner App (основной трекинг) + Sport Store (регистрация покупки + рекомендация замены)

**Связь с экосистемой:** покупка в Store → регистрация в Runner App → трекинг → истощение ресурса → новая покупка в Store

*Статус: идея, требует проработки формулы износа*

### 💡 Набор инструментов бегуна (адаптировать из Simpla)

> Добавлено 2026-06-28. Подсмотрено у конкурента **Simpla** — у них есть набор полезных тренировочных инструментов (см. разбор конкурента).

**Суть:** мини-набор практичных инструментов для бегунов прямо в приложении — для тех, кто реально тренируется и в них нуждается. Берём идею у Simpla и **адаптируем под наш бренд/UX**, не копируя 1:1.

**Какие инструменты:**
- **Калькулятор пульсовых зон** (по возрасту / максимальному пульсу) — зоны Z1–Z5.
- **Интервальный таймер** — настраиваемые интервалы работа/отдых со звуком и вибро.
- **Метроном каденса** — задаёт частоту шагов (шагов/мин) для постановки техники.
- **Конвертер темп ↔ скорость** + расчёт времени / дистанции / темпа.
- **Калькулятор размера кроссовок** (стыкуется со Store — подсказать размер при покупке).

**Зачем:** повышает ценность для продвинутых бегунов (удержание), даёт причину открывать приложение помимо самого забега; часть инструментов (размер кроссовок, каденс) — мостик к Store и к AI-подбору ниже.

**Где интегрировать:** Runner App (Квартал) — раздел «Инструменты»; калькулятор размера — связка со Sport Store.
**Связь с экосистемой:** инструменты → данные о бегуне (каденс, пульсовые зоны, размер) → точнее работают [AI-помощник по подбору](#-ai-помощник-по-подбору-экипировки-не-только-кроссовки) и [трекер износа](#-ресурс-кроссовок-трекер-износа).

### 💡 Совместные забеги и командный захват территории

> Сохранено из раннего черновика идей (2026-06-16). Соц./мультиплеер-направление Runner App.

**Суть:** два и более спортсмена находят друг друга и запускают **совместный забег**; продумать, как считаются маршрут, территория и награда.

**Сценарии:** вместе замыкают один периметр; каждый бежит свою часть, система объединяет треки; клуб запускает **командный вызов** на захват; территория засчитывается, только если участники реально двигались в рамках одного события.

**Что учесть заранее:** отдельная сущность на backend — `group_run`/`team_run` (лучше сразу проектировать `run_session`, к которой привязан один или несколько участников); у каждого свой GPS-трек; объединение территории на сервере через PostGIS; правила античита (мин. дистанция/скорость/время/точность/пересечение по времени); кому баллы — лично, клубу или обоим.

**Главный риск:** если жёстко привязать захват к одному пользователю и одному локальному треку, командные забеги потом добавить сложнее.

*Статус: идея (соц./мультиплеер).*

### 💡 Видимые спортсмены на карте + встроенный чат

> Сохранено из раннего черновика (2026-06-16).

**Суть:** на карте видно других спортсменов рядом/на пробежке (как объекты в 2ГИС); по тапу — написать, пригласить на пробежку или в клуб.

**Функции:** ближайшие активные; статус (бежит / доступен / скрыт); приглашение «давай вместе»; короткий чат внутри приложения; приватность (всем / друзьям / клубу / никому).

**Что учесть:** нельзя слать точную геопозицию всех без согласия; отдельный privacy-режим; live-локации **временные**, не вечные; backend-модуль сообщений для чата; для live-карты позже — WebSocket + Redis + ограничение частоты.

**Риск/рекомендация:** чувствительно по приватности — начинать с безопасного MVP: «виден только друзьям», «виден только во время тренировки», «скрыть меня» одной кнопкой.

*Статус: идея; делать только с понятными настройками видимости.*

### Из партнёрства Suunto (05.10.2026) — канал на часы двусторонний

- **Круг захвата уходит на часы.** Suunto Cloud API принимает маршруты (GPX с точками) и ведёт по
  ним навигацией. Значит, подсказку «Обеги этот круг · 1,2 км» можно отправить прямо на запястье:
  человек видит контур квартала на часах и бежит по нему, не доставая телефон. Геометрия у нас уже
  есть — 632 квартала Якутска.
- **Наш контент во время бега через SuuntoPlus Guides.** Guides показывают на циферблате то, что
  прислал партнёр, прямо в тренировке: интервалы, темп, подсказки. Для Квартала это «до замыкания
  петли 300 м», «квартал взят», раскладка по кругу. Игра уезжает с карты на запястье — такого у
  местных конкурентов нет.
- **Пробежки МАТА — в дневник Suunto.** Можно не только забирать тренировки, но и отправлять свои
  (FIT). Человек бежит с телефоном в Квартале, а тренировка появляется у него в Suunto App.
- **Суточные данные** (шаги, сон, HRV, пульс покоя) — основа для «готов ли ты сегодня бежать»
  и для персональных триггеров (см. память personalized-marketing-plan).

Условие у всех четырёх: часы Suunto, подключённые к Suunto App. Делать после запуска магазина
(часы заморожены D-75), но замысел зафиксирован.

## Идеи по Sport Store

### 💡 Сравнение товаров (таблица сравнения, как в ДНС)

> Добавлено 2026-06-28. Разобран паттерн ДНС (dns-shop.ru/compare) и лучшие практики.

**Суть:** пользователь добавляет несколько товаров «в сравнение» и видит их рядом по характеристикам — сразу понимает, чем они отличаются и что выбрать. Особенно полезно для технически сложного выбора (кроссовки: назначение, вес, дроп, амортизация, пронация, поверхность).

**Как работает (по разбору ДНС):**
- На карточке товара и в каталоге — кнопка/чекбокс **«Сравнить»** (добавить в сравнение).
- Отдельный экран/страница сравнения: **товары — колонки, характеристики — строки**; сверху фото, название, цена, рейтинг.
- **Тумблер «показать только отличия»** — скрывает одинаковые характеристики, оставляет различающиеся (ключевая фишка ДНС).
- До **~5 товаров** одновременно.
- Для кроссовок строки сравнения: назначение (бег/трейл/зал), вес, дроп (перепад), уровень амортизации, тип пронации, сезон, материал верха, цена, рейтинг.

**Плюсы:** ускоряет выбор, снимает «паралич выбора», повышает конверсию на технически сложных товарах; наглядно вместо листания вкладок.
**Минусы/нюансы:** нужна **единая структурированная схема характеристик** у всех товаров (specs как key-value в `catalog`) — иначе сравнивать нечего; на мобильном — горизонтальный скролл/адаптив.

**Где интегрировать:** Sport Store (приложение) **+ Сайт** — одна модель данных и один бэкенд `catalog`.
**Связь с экосистемой:** единый `catalog` хранит атрибуты товара структурированно → и сайт, и приложение строят сравнение из одних данных. **Предусловие общее с идеей AI-подбора ниже** — нормализованные характеристики товаров.

*Статус: идея; предусловие — нормализованная схема характеристик в `catalog`.*

### 💡 AI-помощник по подбору экипировки (не только кроссовки)

> Добавлено 2026-06-28.

**Суть:** ИИ-ассистент-консультант. Пользователь отвечает на вопросы, а ИИ **задаёт встречные наводящие вопросы** (живой диалог), **строит уникальный портрет клиента** и подбирает **кроссовки + полную экипировку** по **уровню подготовки, специализации и ценовой категории**.

**Как работает:**
- **Диалоговый подбор:** ИИ уточняет — уровень (новичок / любитель / продвинутый), **специализацию** (дисциплина/дистанция: спринт, 5–10 км, полумарафон/марафон, трейл), цель (похудеть / здоровье / результат), частоту, поверхность (асфальт / трейл / зал), **ценовую категорию / бюджет**, особенности (пронация, травмы, размер).
- **Уникальный портрет клиента:** из ответов (а со временем — из данных бега в «Квартале» и инструментов: каденс, пульсовые зоны, размер) собирается **сохраняемый профиль бегуна**, который переиспользуется и уточняется при следующих подборах.
- **Наводящие вопросы**, если данных мало — как живой консультант в магазине.
- На выходе — подборка **под уровень и бюджет:** новичку → стартовые бюджетные модели; продвинутому → продвинутые модели; **плюс сопутствующая экипировка комплектом** (одежда, аксессуары), а не только пара кроссовок.
- Подбор строго из **реального каталога** (товары / наличие / цена из `catalog`) — без выдуманных товаров.

**Плюсы:** снимает барьер «не знаю, что выбрать»; повышает средний чек (комплект, а не одна пара); персонализация как у топ-брендов; вовлечение.
**Нюансы/подводные камни:** нужен каталог со **структурированными атрибутами** (та же база, что и для сравнения выше); ИИ подбирает только из реального каталога (RAG/функции по `catalog`, без галлюцинаций); стоимость токенов; модерация ответов; начать можно с правил + LLM поверх. ИИ — на актуальной модели (например, Claude).

**Где интегрировать:** Sport Store **+ Сайт** (диалог), данные из `catalog`; **уровень подготовки может подтягиваться из Runner App** (история бега, км/опыт) — кросс-связь.
**Связь с экосистемой:** уровень бегуна из «Квартала» → точнее подбор в Store → покупка → регистрация кроссовок в Runner App (стыкуется с идеей [трекера износа кроссовок](#-ресурс-кроссовок-трекер-износа)).

*Статус: идея; предусловие — структурированный каталог; запускать после выстраивания каталога/бэкенда.*

### 💡 AI-обработка фотографий товаров (единый стиль каталога)

> Сохранено из раннего черновика (2026-06-16).

**Суть:** сотрудник фотографирует новый товар на телефон → AI приводит фото к единому стилю бренда → после **ручного подтверждения** товар публикуется в каталоге, приложении и на сайте.

**Процесс:** фото → загрузка в backend → AI-обработка в фирменном стиле → проверка/подтверждение сотрудником → публикация в Store и на сайте.

**Что учесть:** хранить **оригинал отдельно** от обработанной версии; публикация только после ручного подтверждения; история обработки; шаблон стиля (фон, свет, кадрирование, цветовая температура); AI **не меняет** форму/цвет/модель/логотип. У товара — несколько изображений со статусами: `original` → `processed` → `approved` → `published`.

*Статус: идея; смыкается с нормализованным каталогом (см. идею AI-подбора выше).*

### 💡 Партнёрская программа для сторонних магазинов (масштабирование)

> ⏳ **Статус: на будущее — реализовывать после полного запуска экосистемы**

**Суть:** Подключать сторонние магазины (спортпит, физио-центры, кафе здорового питания и др.) к экосистеме Кварталов как партнёров.

**Механика:**
- Территория рядом с магазином партнёра = физический трафик бегунов
- Бегуны тратят баллы Кварталов у партнёра как скидку
- Комиссия только за реального клиента (pay-for-performance), не за показы

**Почему это лучше конкурентов:**
- Трафик создаёт игровая механика, а не реклама — люди приходят сами
- Аудитория квалифицирована (активные, спортивные, платёжеспособные)
- Физический трафик в оффлайн-точку — то чего не даёт ни один цифровой канал

**Запуск:** первым партнёрам — бесплатный пробный период 1–2 месяца, затем комиссия

*Реализовывать когда: проект полностью работает, есть активная база пользователей, начинается масштабирование*

## Из разбора конкурента Moneyrun (26.08.2026)

Полный разбор — `docs/RESEARCH_MONEYRUN.md`. Идеи по убыванию отдачи:

- **Импорт тренировок с часов.** Apple HealthKit и Strava — своими силами, дальше Garmin, Polar,

  разрешение дублей, удаление кривой тренировки — на этом конкурент собирает основную массу жалоб.
- **Очки за усилие, а не за километры.** Нагрузка по пульсовым зонам (TRIMP-подобная) с потолками
  на перетренированность: 72-часовой лимит и лимит на тренировку. Честнее к новичкам, устойчивее
  к накрутке, не поощряет «накатать любой ценой».
- **«Своя лига» вместо штрафа за темп.** У конкурента медленный бег просто не оплачивается, и это
  его главный источник злых отзывов. Наш вариант — коэффициент по возрасту/полу/уровню.
- **Клубный бюджет и верификация клуба.** Клубу — кошелёк в баллах, курс, месячный лимит; статус
  верифицированного заслуживают и теряют. Клубы начинают сами приводить и обслуживать людей.
- **Корпоративные клубы как продукт (B2B).** Компания платит рублями за активность сотрудников,
  сотрудники получают баллы, товар отгружает Store — зарабатываем маржой, а не раздаём кэш.
  У конкурента это работает вживую (корпоративный фонд Модульбанка).
- **Гарантированный бонус за норматив** вместо «топ-N»: выполнил — получил, приз не отбирает сосед.
- **Календарь забегов с протоколами** — довести черновик «Стартов» до карточки старта с привязкой
  своей тренировки к официальному протоколу.
- **Публичный ежемесячный отчёт о начислениях** — дёшево, доверие поднимает сильнее функций.
- **Роль куратора в клубе** (у них «Забота») — поддержка силами сообщества за статус и бонусы.
- **Соцмелочи ленты** — отложенная публикация, @-упоминания, «с кем бежал».

**Отдельно — решение, которое нужно принять:** платим ли мы вообще деньгами. Рекомендация из
разбора — нет: у конкурента выплаты держатся на процентах с эндаумента, то есть на ключевой ставке,
а комиссия «минимум 30 ₽» обесценивает мелкие суммы (годовой заработок любителя — 428 ₽).
Баллы + товар + слоты на забеги дают ту же мотивацию и стоят нам себестоимости.

## Из стратегии «своя лига» (27.08.2026)

Полная стратегия — `docs/STRATEGY_KVARTAL.md`. Механики, которых у нас ещё нет:

- **Тропы (сегменты)** — участки маршрутов с четырьмя досками: быстрейшие, мой прогресс,
  чаще всех за 90 дней, моя лига по возрасту и уровню. Плюс тень соперника (бег против записи).
- **Своя лига (гандикап)** — поправки на возраст, пол, уровень, рельеф и мороз, чтобы медленный
  и возрастной бегун соревновался с равными, а не с чемпионом.
- **Мирный режим территорий** — территорию видно, но отобрать нельзя; для тех, кто не хочет PvP.
- **Выбор мотивации на старте** — «зачем ты бегаешь» → главный экран собирается под ответ.
- **Карта безопасного бега** — освещение, людность по времени суток, метки сообщества
  («злые собаки», «гололёд», «нет тротуара») + «смотри за мной» (живая ссылка близкому).
- **Напарник по темпу** — подбор человека рядом с домом на конкретное время.
- **Импорт истории из ушедших сервисов** — GPX/TCX из Strava, Nike, adidas, Garmin.
- **Разряды по-нашему** — лестница уровней с поправкой на возраст и пол как спортивная идентичность.
- **Спокойный режим** — бег без единой цифры на экране.
- **Смысл** — километры в пользу дела (приют, площадка, стадион).
- **Городские квесты** — маршрут-задание по району с историей места.
- **Связка с «5 вёрст»** — карточка локации, свои результаты, клубный зачёт.
