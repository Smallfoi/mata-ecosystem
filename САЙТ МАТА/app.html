Как установить на Android

  1. Нажми «Скачать» — загрузится файл .apk.
  2. Открой скачанный файл (шторка загрузок или «Файлы»).
  3. Android спросит разрешение — включи «Разрешить установку из этого источника», вернись назад.
  4. Нажми «Установить». Готово.
  5. Обновление ставится «поверх» — данные и вход сохраняются.

iPhone / iOS

Скоро. Для iPhone готовим раздачу через TestFlight (официальное приложение Apple для бета-версий). Как только будет готово — пришлём ссылку-приглашение, установка в один тап.
