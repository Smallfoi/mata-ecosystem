# Бренд-кит МАТА (от mudreza) — локальная библиотека

Единое место для исходной айдентики от **mudreza**: логотипы, элементы, цвета, шрифты, брендбук.
Отсюда берём готовый файл и кладём в конкретный продукт, когда нужно.

> ⚠️ **Репозиторий ПУБЛИЧНЫЙ.** Эта папка **не коммитится** целиком (см. `brand/.gitignore`) —
> чтобы весь бренд-кит не оказался в открытом доступе до запуска/Роспатента. Файлы живут
> **локально** на диске. Когда логотип/элемент реально нужен в приложении или на сайте —
> копируем **только этот файл** в `assets/` продукта и коммитим уже его.

## Структура

```
brand/
├── _inbox/      ← СЮДА кидай новые файлы от mudreza (или распакуй архив). Я разложу.
├── brandbook/   Брендбук PDF (правила, логотип, цвета, отступы, применение)
├── logo/        Логотипы: полный, знак, монохром, инверсные, для тёмного/светлого фона
├── elements/    Доп. графика: паттерны, иконки бренда, декоративные элементы
├── color/       Палитра: свотчи, коды цветов (HEX/RGB), градиенты
├── fonts/       Шрифты бренда (если входят в кит)
└── source/      Исходники под правку: AI / PSD / SVG / экспорт из Figma (крупные)
```

## Как пользоваться

1. **Загрузить:** положи файлы в `brand/_inbox/` (можно одним архивом) → скажи мне «готово».
2. **Разложу:** отсортирую по папкам выше и обновлю этот README — таблицу «что где лежит»,
   чтобы любой файл находился за секунду.
3. **Вставить в продукт:** скажешь «нужен логотип X в приложение Store» — скопирую нужный
   экспорт в `mata_store/assets/...` (или на сайт / в админку) и закоммичу **только его**.

## Что доставила mudreza (обзор — по показанному владельцем)

- **Логотип, 2 формы:** (а) **знак** — трилистник/3-лучевая «вертушка» (иконка: app icon, favicon, аватар); (б) **логотип «MATA»** + опц. блок-параллелограмм (шапки, сплэш, шильдики). Обе формы во всех заливках (жёлтый/серый/белый/чёрный/графит) × на цветных фонах.
- **Палитра (3 + ч/б):** жёлтый-лайм `~#E8E77E`, графит-зелёный `~#2B302A`, серо-лиловый `~#B0B2BC` + чёрный/белый. *(точные коды — из брендбука)*
- **Паттерны:** диагональная полоса из смещённых параллелограммов — жёлто-серый и серо-белый (+жёлтая акцент-полоса). Ядро визуала (та же полоса на упаковке).
- **Фирменные элементы:** параллелограмм/ромб (базовый примитив), знак-трилистник, Т-элемент, glow/blur-версии, композиции «МATA» в вырезе полосы. Все — во всех заливках × фонах.
- **Носители:** премиум/эконом-пакеты, подарочная карта (running club / QR «Все условия»), бирки (имидж + товарная), фирм-пакет «MATA running club».
- **Упаковки:** коробка с диагональной полосой + ивент-плашка «ЦИКЛ БЕГА · дата · формат»; премиум-коробка (резинка + T-язычок).
- **Слоган:** «Комфорт, который двигает вперёд». **Оператор:** ИП Татаринова Алена Анатольевна (решение владельца 24.09.2026 — весь проект на это ИП).
- **Шрифты:** ⚠️ нужны **файлами** (`.ttf`/`.otf`) — для встраивания в приложения/сайт. По картинке не подключить.

## Что уже лежит (файлами в этой папке) — кит загружен ✅

| Папка | Что внутри |
|---|---|
| `brandbook/` | `MATA_brandbook_mudreza.pdf` — полный брендбук |
| `logo/` | **SVG-векторы** (`svg/`: знак + лого + лого-доп × белый/жёлтый/серый/чёрный), `с прозрачным фоном/` (PNG), `с фоном/` (PNG), `Логотип.ai` (исходник) |
| `elements/` | фирменные элементы (PNG) + `с прозрачным фоном/` + `с фоном/` |
| `patterns/` | диагональные полосы-паттерны |
| `fonts/` | **Inter** (OTF + variable) и **Roboto Serif** (TTF + variable) — оба OFL, можно встраивать; + `.zip` |
| `carriers/` | носители: пакеты/подарочная карта/этикетка (`.ai` + `.png`) |
| `packaging/` | упаковки: коробки/бумажный пакет (`.ai` + `.png`) |

**Шрифты бренда:** `Inter` (гротеск, основной; уже стоит в Store) + `Roboto Serif` (акцентный serif). Сам логотип «MATA» — кастомный, лежит вектором в `logo/`, не шрифт.

**Ключевые файлы под задачи:**
- иконка приложения / favicon / аватар → `logo/svg/Знак *` (или `logo/с прозрачным фоном/Знак* без фона.png`);
- логотип в шапки/сплэш → `logo/svg/Лого *`;
- фон/баннер → `patterns/`.

*(Кидать новое — в `_inbox/`, разложу. Вся папка `brand/` не коммитится — только этот README и `.gitignore`.)*
