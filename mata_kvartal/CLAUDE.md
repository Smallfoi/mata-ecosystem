# КВАРТАЛ — правила работы (Claude)

Боевое приложение экосистемы МАТА: бег, захват территорий по реальному маршруту,
дивизионы и сезоны, медали «Штамп МАТА», клубы, баллы.

**История имени:** с 29.08 по 05.09.2026 новая геймификация «Квартал 2.0»
строилась в отдельном dev-приложении «ЛИГА» (`mata_liga/`, `ru.mata.liga`).
05.09.2026 по решению владельца эта кодовая база СТАЛА Кварталом (D-70):
«Лига» была временным именем для различия версий. Старый код Квартала удалён,
отдельного dev-приложения больше нет.

## Идентичность
- applicationId / namespace: `ru.mata.kvartal` (обновления встают поверх у тестеров).
- Имя на телефоне: **КВАРТАЛ**. Dart-пакет: `kvartal_app`.
- Канал обновлений: `app/kvartal/version.json` (S3, пишет CI `android-release.yml`).

## Сборки и куда они ходят
- `flutter build apk --debug` → локальный бэк `http://127.0.0.1:8000/v1`
  (нужен `adb reverse tcp:8000 tcp:8000`). Для разработки и проверки на устройстве.
- `flutter build apk --release` (локально НЕ подписывается боевым ключом) →
  прод `https://api.mata-club.ru/v1`. Боевые релизы — ТОЛЬКО через CI
  (Actions → «Android release», релиз-поезд D-58: обычно раз в конце дня).
- Переопределение адреса: `--dart-define=KVARTAL_API_BASE_URL=`.

## Технически
Flutter + Riverpod + go_router. Структура `lib/`: `core/` (роутер, сервисы, тема),
`features/` (экраны по областям), `shared/` (общие виджеты).

```
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
```

Android: AGP 8.9.1, `compileSdk 36`, `minSdk 26`, `MainActivity` наследует
`FlutterFragmentActivity` — требования Health Connect (импорт тренировок с часов).
Без причины Android-часть не трогать.

## Ключевые механики (источники правды)
- Территории (D-09): полигон ВНУТРИ реального маршрута, PostGIS, сервер — судья;
  живой слой 7 дней (D-14), вечный след (footprints). GPS-фильтрация в три слоя
  («Идеальный маршрут», 03.09.2026): трекинг-стражи + чистка трека
  (`route_cleaner.dart`) + серверное морфологическое открытие.
- Квартал 2.0: дивизионы недели / сезоны / вехи / война клубов / дайджест
  (`docs/LEAGUE_PLAN.md`, ECOSYSTEM_API «Квартал 2.0»).
- Медали «Штамп МАТА» (D-64): 44 награды, сервер судит лениво (`/v1/me/medals`),
  зал славы «Пьедестал», каталог за кнопкой «Все медали»; дизайн-эталон
  `docs/design/medals/` — править только через утверждение владельцем.
- Анимации: запрет кругов/ударных волн/пульсов (D-46); планка качества —
  эталоны владельца.

## Правила работы (общие для монорепо — см. корневой CLAUDE.md)
- ветка → PR → зелёный CI → squash; журналы WORKLOG/DECISIONS/PITFALLS;
- дизайн/бренд/цвета/шрифты не трогать без команды владельца;
- контракты API стабильны — на них живут Store и сайт;
- всё временное на диске D (`D:\mata-temp\`), кэши в `D:\dev-cache\`.
